# FileScanner

Консольный сканер файлов для Windows. Рекурсивно обходит указанный каталог,
считает MD5-хеш каждого файла и сверяет его с базой известных хешей. Все
совпадения записываются в лог-файл с вердиктом из базы.

По сути — упрощённый сигнатурный антивирусный сканер: база играет роль набора
сигнатур, а лог — роль отчёта о найденных угрозах.

## Возможности

- Рекурсивный обход каталога (недоступные папки пропускаются).
- Параллельная обработка файлов через пул потоков (по числу ядер CPU).
- Потоковое чтение файлов буфером 4 КБ — большие файлы не грузятся в память целиком.
- Подсчёт MD5 (библиотека [hash-library](https://github.com/stbrumme/hash-library)).
- Лог в кодировке UTF-8, формат CSV с разделителем `;`.
- Счётчик ошибок (недоступные файлы, ошибки чтения и т. п.).

## Архитектура

| Компонент | Назначение |
|-----------|------------|
| `FileScannerLib` | Динамическая библиотека (`.dll`) с основной логикой |
| `scanner` | Консольное приложение — точка входа, разбор аргументов |
| `HashLib` | Реализация MD5 (подтягивается через `FetchContent`) |

Ключевые классы (`FileScannerLib/FileScannerLib.h`):

- **`FileRunner`** — обходит дерево каталогов и раздаёт пути в `ThreadPool`.
- **`ThreadPool`** — очередь задач и рабочие потоки, считающие хеши.
- **`WaitGroup`** — примитив ожидания завершения всех потоков.
- **`Logger`** — загружает базу хешей и пишет совпадения в лог.

## Требования

- Windows
- Visual Studio 2019/2022 с компонентом «Разработка на C++» и CMake
- Компилятор MSVC (`cl.exe`), генератор Ninja
- CMake ≥ 3.15
- Git (нужен для `FetchContent` — библиотека MD5 скачивается при конфигурации)
- Компилятор с поддержкой C++17

## Сборка

### Через Visual Studio

Открыть папку проекта в Visual Studio («Открыть локальную папку»). VS сам
подхватит `CMakePresets.json`. Выбрать конфигурацию (`x64 Debug` / `x64 Release`)
и собрать.

### Через командную строку

Из «Developer Command Prompt for VS»:

```bash
cmake --preset x64-release
cmake --build out/build/x64-release
```

Доступные пресеты: `x64-debug`, `x64-release`, `x86-debug`, `x86-release`.

Результаты сборки:

- `out/bin/scanner.exe` — исполняемый файл
- `out/bin/FileScannerLib.dll` — библиотека (должна лежать рядом с `.exe`)

## Запуск

Два способа передать аргументы.

Позиционно (`<путь> <база> <лог>`):

```bash
scanner.exe C:\Target examples\base.csv logger.txt
```

Именованными флагами (в любом порядке):

```bash
scanner.exe --path C:\Target --base examples\base.csv --log logger.txt
```

| Аргумент | Описание |
|----------|----------|
| `--path` | каталог, который нужно просканировать |
| `--base` | файл базы хешей |
| `--log`  | файл, куда писать отчёт |

Если какой-то из аргументов не задан, программа выведет `Wrong input` и завершится
с кодом `-1`.

## Формат базы хешей

Текстовый файл, одна запись на строку:

```
<md5 в нижнем регистре, 32 симв.>;<вердикт>
```

Пример — [`examples/base.csv`](examples/base.csv):

```
16a92ea9a5686335a256f814db5975df;Miner
665bbf5ed7f6b4d8b68d73617bcd5136;Worm
```

Разделитель — один символ `;` на позиции 33. Строки короче 34 символов считаются
ошибкой формата.

## Формат лога

CSV в UTF-8, одна строка на найденное совпадение:

```
<полный путь к файлу>;<md5>;<вердикт>
```

Файлы, чей хеш не найден в базе, в лог не попадают.

## Замечания

- Консоль переключается в кодовую страницу 1251 (`SetConsoleCP`), лог пишется в UTF-8.
- MD5 не криптостоек — годится для сверки сигнатур, но не для проверки целостности
  от намеренной подмены.
- `error_counter` — глобальный счётчик; при нескольких запусках в одном процессе
  не обнуляется.
